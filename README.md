# A2 Imóveis

Aplicativo imobiliário desenvolvido em React Native com Expo, voltado à consulta de imóveis e ao gerenciamento de anúncios. Reúne cadastro e autenticação de usuários, visualização de detalhes dos imóveis, perfil e uma área para proprietários acompanharem seus anúncios.

Os proprietários podem enviar solicitações de anúncio com informações, fotos e comprovante. A área administrativa permite analisar, aprovar ou recusar solicitações e gerenciar os registros. O projeto utiliza Firebase para autenticação e dados, além de Cloudinary para envio de imagens.
